TRAKKCONVERTER

Samples to SP-404MK2 WAV

Drop your drum kits and sample packs in. TRAKKCONVERTER batch-converts them to the format the SP-404MK2 actually accepts, keeping your folder structure.

Download for Windows View the source

What it does

  • 48 kHz / 16-bit / stereo That is the SP-404MK2 internal format. Deliver anything else and the sampler resamples on import or rejects the file.
  • No re-converting Files with the _sp.wav suffix are skipped automatically, so a mirror folder is never processed twice.
  • Copy or convert Files already at the target are copied without re-encoding; files at another rate are resampled.
  • Anything FFmpeg decodes MP3, AAC, FLAC, AIFF, OGG, M4A and WAV on input.

How to use it

  1. Add your folder Drag files or the whole folder into the window, or press Add folder.
  2. Pick the output Same folder as the source, or a new one keeping the structure.
  3. Check the preview It shows what will be copied, converted or skipped before touching anything.
  4. Press START Runs the batch and shows a summary when it finishes.

Frequently asked questions

Do I need FFmpeg installed?

No. The portable .exe bundles it. You only need it if you run from source.

Do I lose quality going from MP3 to WAV?

The MP3 already lost information and it does not come back. What you avoid is a second encode, and you get a file the sampler accepts as-is.

Is it free?

Yes. MIT licensed, no account, no usage limit.

Does it work offline?

Yes. Everything runs on your machine.

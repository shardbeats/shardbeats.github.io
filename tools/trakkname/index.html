TRAKKNAME

Generador de títulos de beats

Poner nombre a un beat no debería costarte veinte minutos. TRAKKNAME combina artistas ponderados por género, vocabulario bilingüe y un eje de moods para darte un título usable al instante.

Descargar para Windows Ver el código Versión Android

Qué hace

  • Ocho patrones de generación Cuatro en inglés y cuatro en español, con concordancia de adjetivos en español.
  • Eje de moods Los 20 moods habituales del type beat, con dos seleccionables a la vez y búsqueda.
  • Sin repeticiones Los artistas no se repiten dentro de una generación y hay ventana anti-duplicados en los títulos.
  • Base de datos editable Artistas, palabras, patrones e historial, con importación y exportación JSON.

Cómo se usa

  1. Elige género e idioma El pool de artistas y el banco de palabras cambian con cada uno.
  2. Marca uno o dos moods Opcional. Vacío significa cualquiera.
  3. Pulsa Space Genera al instante. Ctrl+C copia el título.
  4. Guarda el historial Cada título queda con su género, idioma, mood y artistas.

Preguntas frecuentes

¿Puedo usar los títulos comercialmente?

Sí. Son texto generado, no material con derechos, y no requieren atribución.

¿Se repiten los títulos?

Hay una ventana anti-duplicados y los artistas no se repiten dentro de una misma generación.

¿Puedo editar las palabras y los artistas?

Sí. La base de datos tiene CRUD completo, importación y exportación JSON, y un reinicio a los datos de fábrica.

¿Hay versión para Android?

Sí, con el mismo motor.

TRAKKNORMALIZER

Normalización por pico, clip por clip

Un kick a -18 dB junto a otro a -3 dB rompen el balance de tu beat. TRAKKNORMALIZER mide cada archivo y le aplica solo la ganancia que necesita, en lugar de subirlo todo lo mismo.

Descargar para Windows Ver el código

Qué hace

  • Por clip, no por lote Un normalizador convencional sube todo por igual y hace recortar lo que ya estaba alto.
  • Solo ganancia lineal Sin compresión ni limitador: los transitorios de tus samples no cambian.
  • Conserva el original Frecuencia y profundidad intactas. Los procesados llevan sufijo _N y no se reprocesan.
  • Recrea la estructura Reproduce las carpetas de origen en la salida, para no perder el orden de la librería.

Cómo se usa

  1. Arrastra archivos o carpetas O usa Add folder para añadir una librería completa.
  2. Elige el objetivo Por defecto -1.0 dB, con 0.5 dB de tolerancia para saltar lo que ya está en rango.
  3. Decide la salida Misma carpeta que el origen o una carpeta de salida, con la estructura recreada.
  4. Pulsa START Procesa en paralelo y muestra el progreso por archivo.

Preguntas frecuentes

¿En qué se diferencia de un normalizador normal?

Un normalizador convencional aplica la misma ganancia a todo. Este mide cada archivo y le aplica la suya, así el resultado queda parejo.

¿Cambia el sonido de mis samples?

No hay compresión ni limitación, solo ganancia. La forma de onda se conserva, escalada.

¿Va a reprocesar archivos ya normalizados?

No. Los archivos con sufijo _N se saltan en las siguientes pasadas.

¿Es gratis?

Sí. Licencia MIT, sin cuenta y sin límite de uso.
